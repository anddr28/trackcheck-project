# ТрекЧек

Определяет службу доставки по трек-номеру и открывает её официальный сайт с подставленным номером. Статус посылки ТрекЧек сам не показывает. Номера не уходят на сервер: всё распознавание идёт в браузере.

```
packages/detector   модуль определения (сайт и будущий бот)
apps/web            сайт: Astro, статическая сборка, без фреймворка на клиенте
apps/playground     песочница детектора для ручной проверки
apps/bot            Telegram-бот — этап 4
docs/               исследования, ссылки на отслеживание, протокол суда
```

## Запуск

Нужен Node.js 20+.

```sh
npm install
npm run dev              # сайт: http://localhost:4321
npm run build            # сборка в apps/web/dist
npm run preview -w @trackcheck/web   # собранная версия
npm test                 # тесты детектора
npm run typecheck        # проверка типов
npm run check:colors -w @trackcheck/web   # цвета: правила палитры и контраст WCAG AA
npm run dev:playground   # песочница детектора
```

## Публикация на GitHub Pages

Сайт собирается и публикуется workflow `.github/workflows/pages.yml` при каждом push в `main`: сначала тесты, затем сборка Astro, затем публикация `apps/web/dist`.

Один раз в настройках репозитория: **Settings → Pages → Build and deployment → Source: GitHub Actions**. Если оставить «Deploy from a branch», GitHub запускает Jekyll по исходникам и падает на файлах `.astro`.

Адрес — `https://<владелец>.github.io/<репозиторий>/`: все пути на сайте строятся от этого базового пути (`BASE_PATH`). Для своего домена задайте в workflow `SITE_URL=https://домен` и `BASE_PATH=/`.

## Что заполнить перед запуском

Все такие места помечены `ЗАПОЛНИТЬ`:

- `apps/web/src/config.ts` — `DONATE_URL` (ссылка на кошелёк; QR-код из неё собирается при сборке в `/donate-qr.svg`), `BOT_URL` и `BOT_ENABLED` (ссылка на бота скрыта, пока флаг выключен);
- адрес сайта — переменные `SITE_URL` и `BASE_PATH` в `.github/workflows/pages.yml` (нужны на этапе 3 для canonical и sitemap).

## Сайт

- **Главный экран** — один скрипт на TypeScript, встроенный в HTML вместе с CSS. На «быстром 3G» результат появляется меньше чем за секунду. Номер, вставленный до загрузки скрипта, тоже распознаётся.
- **Ссылка на результат** — `/#номер` (несколько номеров — через запятую). Часть адреса после `#` не отправляется на сервер.
- **История** хранится в `localStorage` браузера (`trackcheck:history:v1`), не больше 100 номеров, с подписями.
- **PWA**: `public/manifest.webmanifest`, `public/sw.js`. Страницы берутся из сети, а без сети — из кэша. Шрифты и иконки берутся из кэша и обновляются в фоне. После первого посещения сайт работает офлайн. При изменении `sw.js` увеличьте версию в `CACHE`.
- **Иконки** — `public/favicon.svg` и `public/icons/maskable.svg`. PNG-иконки (32, 180, 192, 512, maskable 512) сделаны из этих SVG: при правке знака их нужно пересоздать.
- **Дизайн**: все цвета, размеры и отступы — в `apps/web/src/styles/tokens.css`. Тема — как в системе, ручной выбор запоминается, тема применяется до отрисовки.

## Детектор

```ts
import { detect, detectAll } from '@trackcheck/detector';

detect('СДЭК 1150362728');      // кандидаты, подсказки, служба из текста (context), несовпадение со службой (named)
detectAll('текст письма с несколькими номерами');
```

- `confidence`: `high` / `medium` / `low`; `rank`: `likely` («Скорее всего»), остальные — `possible`.
- `number` — чистый номер для кнопки «Копировать», `display` — для показа, `carrierGen` — название в родительном падеже.
- `fallback` — 17TRACK. Значение `null` означает, что это точно не трек (номер заказа, карта, дата).

## Как добавить службу

1. Найдите формат номера и 2–3 реальных примера. Без источника правило не добавляем; если формат подтвердить не удалось — уверенность `low`.
2. Добавьте службу в `packages/detector/src/carriers.ts`: `id`, `name`, `nameGen` (если название склоняется), `slug`, `site`, `tracking` (шаблон с `{n}` и `verified`).
3. Добавьте правило в `packages/detector/src/rules.ts`. Поле `form` задаёт, с какой формой ввода сравнивать:
   - `plain` — латиница без дефисов;
   - `lat` — с дефисами;
   - `cyr*` — кириллические номера.

   Если дефис во вводе означает другую службу, поставьте `noHyphen`.
4. Источники, примеры и оговорки — в `packages/detector/src/rules-meta.ts` (в браузер не попадают; тесты проверяют, что каждый пример распознаётся своим правилом).
5. Если название службы пишут рядом с номером, добавьте его в `CARRIER_WORDS` (`normalize.ts`).
6. Обновите `docs/tracking-links.md` и запустите `npm test`.
